# Use your workspace

Create drawings, organize them into collections, and share them with collaborators.

## Create a drawing

1. On the dashboard, select **New Drawing**.
2. Draw on the canvas. Changes save automatically.
3. Select the drawing title to rename it.
4. Return to the dashboard with the back arrow.

![Drawings organized into collections in the dashboard](/images/workspace.png)

## Organize drawings

Select the **+** beside **Collections**, enter a name, and press **Enter**. Drag a drawing into a collection, or select drawings and use the move action in the dashboard toolbar.

Use the search field to find drawings by name. Change the sort field and direction to reorder the grid.

## Share and collaborate

1. Open a drawing and select **Share** in the top toolbar.
2. Add a person with view or edit access, or configure a share link.
3. Send the link to your collaborator.

View access allows reading; edit access allows changing the drawing. Connected collaborators appear as avatars and named cursors.

![Four collaborators reviewing a deployment diagram](/images/collaboration.png)

To share a collection, open its context menu in the sidebar and select the share action.

## Import and export

Select **Import drawings** on the dashboard to import Excalidraw files. Select **Export drawing** in the editor toolbar to download the drawing and its images. To export PNG or SVG, open the editor menu and select **Export image**.

## Restore a version

Open a drawing you can edit and select **Version History**. Choose a snapshot to inspect or restore. Snapshots are retained for two days by default; change `SNAPSHOT_RETENTION_DAYS` to keep them longer.
